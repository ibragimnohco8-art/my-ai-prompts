⏰ Расписание

Gemini работает автоматически каждые 24 часа через GitHub Actions или Supabase Cron. Файл конфигурации включён в архив.

🤖 Следующий запуск: каждый день в 06:00 МСК (03:00 UTC)

➕ Добавить новые промты

Gemini сгенерирует по 3 промта для каждой из 5 категорий (15 промтов) на основе актуальных трендов.

Нажмите кнопку чтобы начать...

✨ Улучшить описания

Gemini улучшит описания и заполнит пустые поля у промтов без описания (до 20 за раз).

Нажмите кнопку чтобы начать...

🗑️ Очистка базы

Удалит AI-сгенерированные промты старше 60 дней с 0 лайками и менее 5 просмотров. Промты добавленные вручную не затрагиваются.

Нажмите кнопку чтобы начать...

🚀 Запустить всё сразу

Выполнит весь цикл: генерация → улучшение → теги → очистка. Аналог автоматического ежедневного запуска.
